# About

Add New Menu Builder is a Shared Orbit plugin for customizing the Unreal Editor Content Browser's **Add New** menu.

It provides an editor tab where you can create asset shortcuts and categories, choose asset classes, set labels and icons, and arrange those items alongside Unreal's menu headings.

The plugin is Editor-only. Assets created through its menu are normal Unreal project assets.

Start with [Quick Start](/guide/quick-start), or read the plugin [source repository](https://github.com/SharedOrbit/AddNewMenuBuilder).
