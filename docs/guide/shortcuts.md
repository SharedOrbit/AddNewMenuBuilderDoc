# Shortcuts

A shortcut places an asset creation action directly in the Content Browser's **Add New** menu. The Shortcuts page shows Unreal's built-in shortcuts and your own items in one list.

## Add a shortcut

1. Open **Add New Menu Builder** and select **Shortcuts**.
2. Click **+** beside the list. A new custom shortcut is inserted at the top.
3. Select it and set **Name**, **Tooltip**, and **Asset Class**.
4. Optionally choose an **Icon** from a Texture2D asset.

The status text below the details tells you whether the selected class can be used for asset creation. See [Asset Classes & Icons](/reference/asset-classes) for how classes are resolved.

## Change or remove a shortcut

Select a **Custom** row to edit its details. Use **−** or the row's context menu to remove it. The context menu also provides **Move Up** and **Move Down** actions.

Unreal rows can be repositioned in the combined shortcut list. Their built-in asset actions cannot be renamed or removed here.

## Shortcut order

Drag a row to the desired position, or use the row's move actions. Click the refresh icon beside **Shortcuts** to reset the saved shortcut order. New custom shortcuts start at the top of the list.

For what you can reorder, see [Rules](/guide/rules).
