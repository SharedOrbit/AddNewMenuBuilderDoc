# Quick Start

This walkthrough creates one top-level shortcut and one custom category. You can do both in the **Add New Menu Builder** editor tab.

::: tip Before you begin
Install the plugin and open its editor tab from the Content Browser's **Add New** menu. Work in a folder where Unreal allows new assets.
:::

## 1. Create a shortcut

1. Select **Shortcuts** at the top of the editor tab.
2. Click **+** beside the Shortcuts list. The new item appears at the top.
3. Select the new row and enter a **Name**, such as `Material`.
4. Choose **Material** as the **Asset Class**. Add a **Tooltip** or **Icon** if you want one.

Open the Content Browser's **Add New** menu again. Your shortcut should appear with Unreal's built-in shortcuts. Choose it to start creating the asset in the current folder.

## 2. Create a category

1. Select **Categories** at the top of the editor tab.
2. Click **+** beside the Categories list and give the new category a clear **Name**.
3. With that category selected, click **+** beside **Entries**.
4. Give the entry a **Name** and choose a creatable **Asset Class**.

The new category appears in the Content Browser's **Add New** menu. Its entries appear inside its submenu. You can add more entries to the same category.

## 3. Organize the menu

Drag shortcut or category rows to change their position. The lists contain both Unreal and custom rows, labeled **Unreal** and **Custom**. Use the refresh icon beside either list to reset that list's order.

You can arrange an Unreal category heading, but the assets inside that built-in category remain controlled by Unreal. See [Ordering](/guide/ordering) for the rules and version differences.

## 4. Check the result

Reopen **Add New** in the Content Browser and verify the shortcut, category, entry, and asset creation. If the chosen class is unavailable, review [Asset Classes & Icons](/reference/asset-classes).
