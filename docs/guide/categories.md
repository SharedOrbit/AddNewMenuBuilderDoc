# Categories

A category creates a submenu in the Content Browser's **Add New** menu. The Categories page shows Unreal category headings and your custom categories together.

## Add a category

1. Open **Add New Menu Builder** and select **Categories**.
2. Click **+** beside the Categories list.
3. Select the new **Custom** row and set its **Name** and optional **Tooltip**.
4. Add assets to the category through the **Entries** section.

See [Category Entries](/guide/entries) for the entry fields and creation flow.

## Edit, remove, or move

Custom category names and tooltips can be edited in the details panel. Use **−** or the context menu to remove a selected custom category. Removing it also removes its custom entries from the menu.

Drag category rows or use **Move Up** and **Move Down** in the context menu. The refresh icon beside **Categories** resets the saved category order.

An **Unreal** category heading can be moved in the combined list. The entries inside an Unreal category are built-in and are not edited or reordered by this panel.

::: tip
Use a short category name that describes the assets inside it. A category with no entries has nothing useful to show in its submenu.
:::
