# Version Updates

## 1.0

The initial documentation describes the current editor workflow:

- Custom shortcuts in the Content Browser's **Add New** menu.
- Custom categories containing asset creation entries.
- Combined Unreal and custom shortcut/category lists.
- Ordering and reset controls.
- Asset Class, tooltip, and optional Texture2D icon fields.

This page will track documentation and plugin updates as they are published. See [Compatibility](/reference/compatibility) for engine-specific behavior.
